# MSS Locked Product Plan

## Product

MSS is a real coaching/course-selling online platform for Bangladeshi academic students.

It is not a simple LMS, not just a landing page, and not a temporary MVP.

## Core Direction

- Nx monorepo
- Angular frontend
- Angular Material + Tailwind CSS
- Supabase backend
- PostgreSQL database
- Supabase Auth
- Supabase Row-Level Security
- Supabase Storage
- Supabase Edge Functions
- Cloudflare Pages deployment
- Free-resource-first development
- Agile sprint workflow
- DRY and SOLID design principles

## Main Roles

- Super Admin
- Admin
- Teacher
- Student
- Support

## Main Modules

- Public website
- Course catalog
- Course detail page
- Enrollment and payment flow
- Student dashboard
- Teacher dashboard
- Admin dashboard
- Lesson player
- Materials/resource library
- Quizzes/tests
- Progress tracking
- Support tickets
- Notifications
- Device/session control
- Audit logs

## Video Strategy

Initial free setup:

- YouTube Unlisted
- youtube-nocookie embed
- Student watermark
- Session/device control
- Playback audit log

Future upgrade path:

- Cloudflare Stream or Bunny Stream

## Rule

Use free resources first. Paid tools/services only if absolutely necessary later.
