How Enrollment Works

Simple manual payment flow for Bangladesh.

MSS keeps enrollment familiar: select course, pay with mobile financial service, submit transaction details, then wait for admin approval.

Step 1 Choose course

Select a course or package from the catalog.

Step 2 Pay via MFS

Use bKash, Nagad, or Rocket according to the given instruction.

Step 3 Submit TXN ID

Send payment number, transaction ID, and optional note.

Step 4 Access unlocked

Admin verifies payment and activates the student dashboard access.
