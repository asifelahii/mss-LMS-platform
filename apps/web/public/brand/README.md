# MSS Logo Asset Pack

These files were generated from the official MSS PNG logo supplied in the chat.

Recommended placement inside the Nx Angular project:

- Put `favicon.ico`, `favicon-16x16.png`, `favicon-32x32.png`, `apple-touch-icon.png`, `android-chrome-192x192.png`, `android-chrome-512x512.png`, `maskable-icon-192x192.png`, `maskable-icon-512x512.png`, and `site.webmanifest` inside:
  `apps/web/public/`

- Put `mss-logo-cropped-transparent.png`, `mss-logo-cropped-transparent@2x.png`, `mss-logo-cropped-transparent.webp`, `mss-logo-embedded.svg`, `mss-logo-navbar-240w.png`, `mss-logo-white-background.png`, and `mss-logo-dark-background.png` inside:
  `apps/web/public/brand/`

Note: `mss-logo-embedded.svg` is not a true editable vector redraw. It is an SVG wrapper that embeds the raster PNG so it can be used in SVG-compatible web contexts. For true vector editing, the logo should be manually redrawn/traced in Figma or Illustrator.
